# Security Policy

## Reporting a Vulnerability

All security bugs about Scriggo should be reported by opening a
[confidential issue](https://gitlab.com/haproxy-haptic/scriggo/-/issues/new?issue[confidential]=true)
on this GitLab project.

## Flagging Existing Issues as Security-related

If you believe that an existing issue is security-related, we ask that you open a
[confidential issue](https://gitlab.com/haproxy-haptic/scriggo/-/issues/new?issue[confidential]=true)
referencing the issue ID and including a short description of why it should be
handled according to this security policy.
